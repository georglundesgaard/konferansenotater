# Bootiful Spring Boot 4

*Dag 1, 2. september 2026 · kl 11:40 · Josh Long · 📋 [i programmet](../program.md#d1-1140) · 🌐 [offisiell beskrivelse](https://2026.javazone.no/program/29c54f57-6378-4665-8737-522f944c657d)*

Josh Long tar for seg hva som er nytt når Spring Boot 4 og Java 25 møtes, i sin karakteristiske livekodende stil. Utgangspunktet er hvordan man skalerer både applikasjoner og kodebaser, og han viser bredden i dagens Spring-økosystem: AI-integrasjon med Spring AI, den nye modulariteten i rammeverket, forenklet dataaksess og innebygd sikkerhet.

En sentral del av foredraget handler om produksjonsoptimaliseringer på moderne JVM: virtuelle tråder fra Project Loom for enkel skalering av samtidighet, GraalVM native images for raskere oppstart og lavere minnebruk, og AppCDS for kortere oppstartstid. Budskapet er at kombinasjonen Spring Boot 4 og Java 25 lar deg bygge raskere, mer modulære, sikrere og mer «intelligente» systemer med relativt liten innsats.
