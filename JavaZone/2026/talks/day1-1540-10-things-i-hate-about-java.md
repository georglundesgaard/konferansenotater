# 10 Things I Hate About Java

*Dag 1, 2. september 2026 · kl 15:40 · Adele Carpenter · 📋 [i programmet](../program.md#d1-1540) · 🌐 [offisiell beskrivelse](https://2026.javazone.no/program/58719c5f-f01f-46b1-bd00-ca8df0df8d7b)*

Adele Carpenter tar en lettbeint, ærlig gjennomgang av det mest frustrerende ved Java som hverdagsspråk – ordrikt og klumpete, med alle veier tilsynelatende pekende mot null, akkurat slik C#-brukere elsker å påpeke.

Samtidig er poenget dobbelt: Java er modent, stabilt, bakoverkompatibelt og kjører overalt – og fellesskapet er en styrke. Foredraget følger språkets utvikling over tid og peker fremover, med lovnad om både latter og en og annen tåre.
