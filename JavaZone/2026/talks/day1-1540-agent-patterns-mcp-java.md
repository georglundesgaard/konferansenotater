# Building Intelligent Java Apps: Agent Patterns, MCP, and the Future of AI Native Design

*Dag 1, 2. september 2026 · kl 15:40 · Daniel Oh · 📋 [i programmet](../program.md#d1-1540) · 🌐 [offisiell beskrivelse](https://2026.javazone.no/program/1a6f75e1-b192-4b86-b2a3-3932aa1baf60)*

Daniel Oh tegner Java-utviklerens reise fra modelleksperimenter til produksjonsklare AI-applikasjoner, sett gjennom agentbasert arkitektur: systemer som resonnerer, interagerer og tilpasser seg.

Sentralt står Model Context Protocol (MCP) og Agent2Agent-kommunikasjon (A2A) som byggesteinene som flytter oss forbi enkle prompt-svar-interaksjoner, mot multiagent-arkitekturer og kontekstbevisste tjenester i AI-native Java-design.
