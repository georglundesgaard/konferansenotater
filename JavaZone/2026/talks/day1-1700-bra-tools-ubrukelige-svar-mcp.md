# Bra tools, ubrukelige svar: Læring fra ett år med MCP

*Dag 1, 2. september 2026 · kl 17:00 · Bjørn Nordlund, Eirik Fagtun Kjærnli · 📋 [i programmet](../program.md#d1-1700) · 🌐 [offisiell beskrivelse](https://2026.javazone.no/program/1f42fc0f-4e1a-4aaf-b397-1c6a965e3b31)*

Nordlund og Kjærnli avviser at «MCP er dødt» med et års praktisk erfaring: De har bygget og eksponert funksjonalitet via MCP for administratorer som håndterer millioner av Cisco-enheter for kommunikasjon og samarbeid verden over – med reelle krav til skala, sikkerhet og stabilitet.

Poenget i tittelen er lærdommen: gode tools er ikke nok når svarene blir ubrukelige. MCP-serveren deres er bygget for kunder, ikke for én bestemt agentopplevelse – og foredraget deler hva som faktisk krevdes for å få det til.
